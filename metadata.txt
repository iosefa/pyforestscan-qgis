Native point-cloud processing requires QGIS 4.2+, its PDAL Processing provider, NumPy 2.3.1+, SciPy 1.16+ and GDAL. QGIS 3.40/4.0 and installations missing these capabilities need the optional isolated engine, installed through Plugins > PyForestScan > Set up PyForestScan. Engine setup needs internet access and additional disk space; packages support Windows x64, Linux x64 and macOS Intel/Apple Silicon. See bundled help for installation and tested-platform limits.
